headroom results

Mastering decisions graded by measurement, not by an LLM's opinion.

Every system below runs inside the same loop, against the same degraded input, with the same render budget, and is scored by the same deterministic feature vector. recovery is 1 - final/initial distance: 1.0 is a perfect repair, 0 is no progress, negative means the system made the audio worse. optimizer is a measured upper bound rather than a competitor — it gets hundreds of renders instead of 4 and is seeded with the other systems' answers, so it says what was achievable, not what is practical.

Inside the agent

Four specialists, each holding exclusive write access to the ops that move the dimensions it owns, routed by a deterministic supervisor that picks whichever role carries the largest weighted error. A specialist is shown only its own dimensions — the other eighteen to twenty-six are not in its prompt at all — and it may make several coordinated edits per render, where the heuristic makes one. That difference is the architecture's whole numeric claim, so edits/turn is reported rather than asserted.
